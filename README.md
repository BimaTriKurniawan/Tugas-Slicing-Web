Disini aku melakukan slicing website portofolio dari temenku. Di website temenku ini aku hanya mengambil beberapa bagian saja.
Hal ini dikarenakan keterbatasan waktu dan sumber daya manusia. Di website yang ku slicing ini sendiri tidak menggunakan JS. Jadi aku harus membuat JS sesuai ide yang dapat kupikirkan.
Hal yang kutambahkan dari fitur JS nya hanyalah fitur dark dan light mode. Karena fitur lain untuk website portofolio kurasa sudah cukup hanya menggunakan HTML dan CSS.

Fitur yang ada di website ini diantaranya adalah
1. Adanya fitur anchor atau hyperlink dari media sosial dan gihub ku.
2. Adanya fitur anchor yang untuk menuju slide yang mengandung informasi yang diinginkan.
3. Selanjutnta adalah fitur Dark mode dan light mode yang dibuat menggunakan JS. Fitur ini menmanfaatkan penyimpanan local untuk memyimpan mode terakhir yang digunakan.

Kekurangan yang ada dalam website ini adalah
1. Hanya mampu melakukan slicing beberapa bagian saja dari website slicing
2. Ini lebih personal tapi kesalahan ku adalah melakukan slicing website yang tidak ada JS jadi hanya menambah yang kupikirkan.
3. fitur anchor mail ku yang terdapat bug.
4. Kaku animasi dikarenakan tidak ada sentuhan js dan css di bagian animasi.
